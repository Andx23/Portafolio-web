# INSEPTION® — Creative Portfolio

**Digital Experiences. Creative Thinking.**

INSEPTION is my personal creative and professional portfolio, developed to showcase my work, technical skills, experience, and services across multimedia communication and web development.

The project combines a cinematic visual identity with a responsive web experience, bringing together design, code, and creativity.

## Overview

This portfolio represents my professional profile as a **Multimedia Communication Specialist and Front-End / Full-Stack Developer**.

It was designed to present my background, creative projects, technical expertise, and professional services through a visually engaging and accessible interface.

## Sections

- **Home:** Introduction, personal branding, social links, and downloadable documents.
- **About Me:** Professional profile and personal presentation.
- **Expertise:** Technical skills and areas of knowledge.
- **Projects:** Selected creative and development projects.
- **Experience:** Academic background and professional experience.
- **Services:** Digital and creative services.
- **Contact:** Direct contact channels and professional social networks.

## Technologies

The project is built using:

- **HTML5:** Semantic structure and accessible content.
- **CSS3:** Layout, responsive design, animations, and visual styling.
- **JavaScript:** Interactive components, navigation, and functionality.

No front-end frameworks are required.

## Design & Identity

INSEPTION follows a cinematic and minimalist visual direction, featuring:

- Dark visual environment.
- Red accent color palette.
- Editorial typography.
- Geometric visual elements.
- Responsive layouts.
- Subtle transitions and animations.

## Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd INSEPTION
   ```

3. Open `index.html` in your browser or use the Live Server extension in Visual Studio Code.
